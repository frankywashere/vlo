# Meta full-person masks and guided manual review

The former hosted SAM path could run out of memory on a valid 30-second clip,
and a point on a face could produce only a head mask. New jobs can use Meta
SAM 3.1 for full-visible-person masks while keeping the chosen MiniMax/Kling
generation model and optional depth provider independent.

## Shared pipeline

- Admin has separate SAM choices: our worker, Replicate, or Meta. The prior
  preparation-provider setting remains the depth provider. Missing SAM settings
  retain the legacy route; editing depth does not silently migrate masks.
- New upload tickets pin their routes, credential versions, mesh, depth and audio
  settings at acceptance. Existing jobs and accepted tickets retain those values.
- The server extracts each distinct selected original-RGB frame and uses an image
  `person` lookup. It accepts only a unique mask containing the user's actual tap,
  derives the real inclusive body box and a verified interior point, and then
  submits one selected-only video request. Later anchors use both directions so
  the entire trimmed timeline is preserved. Explicit replace-everyone mode uses
  concept tracking and retains the union of overlapping instances.
- The selected mask archive uses the existing categorical IDs, nearest-neighbor
  resizing, identity matching, scene review, tint validation, guide composition,
  audio, model/resolution rules, progress and Library delivery. Private
  CharacterSwap routes continue to bypass this guide preparation.
- Kling's old >15-second Replicate override is retained for legacy non-Meta
  intake but no longer replaces an explicitly selected Meta route. Kling still
  uses no mesh/depth; MiniMax retains its own mesh/depth settings and 15-second
  maximum, including 768p and 2K guide handling.
- Missing/ambiguous initial taps reopen source selections before a paid video
  request. Same-frame corrections reuse the saved image lookup. Confirmation
  queues preparation and returns to guide review; it never marks a stale guide
  ready or starts generation. Scene mask recovery uses the saved SAM provider,
  is bounded to the chosen scene, and preserves other selected people's pixels.
- If the initial Meta video still misses a selected anchor, automatic matching
  and Easy Mode stop for review instead of starting another paid recovery batch.
  The no-review matching setting cannot bypass this limit. A separately requested
  manual scene recovery keeps its own bounded batch preflight.
- Corrected attempts receive fresh private artifact paths, preserve previous
  immutable media, and use monotonically increasing review revisions. Obsolete
  review plans/choices and generation approvals are cleared before rebuilding.
  Logical request identities use the original source and saved selections;
  transcoding differences are fingerprint mismatches, never new paid operations.
- Durable intent precedes every POST. Completed private stream checkpoints can
  be replayed; an incomplete or unconfirmed POST is never automatically recreated.
  The exact redacted prompt/settings, source hash, timing and usage estimates are
  retained privately. Safe preparation failure reasons are visible to credit users.

See [adapter details](META_SAM_ADAPTER.md) for parser pinning, validation, storage
and replay contracts.

## Manual review

Create and Library share one walkthrough: replacement photo and name above a
single source frame, all required scenes for one character before the next,
explicit selection or absence before Next, retained Back choices, and final-only
submission. The initial Meta seed-repair screen requires a person selection and
offers Build person masks, with automatic generation disabled. Desktop/mobile
layouts keep navigation visible and preserve original selection coordinates.
The normal instruction is simply: "Tap the person to replace with the character
above." Reference filenames, duplicate helper text and the small source-face
thumbnail are omitted.
